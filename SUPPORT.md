## Bugs and feature requests

Use the GitHub issue templates. Include the version, Windows version, command
or screen, expected behavior, actual behavior, and a redacted log excerpt.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## What maintainers cannot help with

- Creating or rotating your Google, LLM, Exa, or Gmail credentials.
- Recovering a lost `.env`, database, or Windows account.
- Quota increases or provider billing.
- Private channel analytics that require your Google account.
- Debugging a modified build without its exact source and dependency versions.
