# Icônes Tabler

Les PNG de ce dossier sont générés à partir des icônes **Tabler Icons**, via
l'API publique Iconify (`https://api.iconify.design`).

- Source : https://github.com/tabler/tabler-icons
- Galerie : https://icones.js.org
- Licence : MIT

Les fichiers PNG ne sont pas des dépendances d'exécution : ils sont livrés avec
l'application et teintés à la volée par Pillow.
