# Code of Conduct

## Our pledge

We want participation in Outly to be harassment-free for everyone, regardless
of age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be direct about code and kind about people.
- Assume good faith, ask for context, and critique the work, not the person.
- Respect privacy. Do not ask for or publish keys, tokens, databases, private
  analytics, or personal channel data.
- Accept that maintainers may close low-effort, duplicate, or out-of-scope
  reports with an explanation.
- Follow the provider terms that make the project possible.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or sexualized attention.
- Publishing another person's private information without permission.
- Deliberately exposing secrets, personal data, or private analytics.
- Spam, sustained disruption, or bad-faith demands on unpaid maintainers.
- Encouraging quota abuse, API terms violations, or unauthorized scraping.

## Scope

This code applies in the repository, issue tracker, pull requests, discussions,
and any project space. It also applies when representing the project elsewhere.

## Reporting and enforcement

Report a conduct problem privately to the maintainers through the repository's
GitHub profile or a GitHub Security Advisory. Do not include sensitive personal
data in a public issue. Maintainers will review reports in good faith and may
warn, remove content, lock a thread, or ban participation. Retaliation against
a reporter is itself a violation.

This is a concise project code of conduct, not legal advice.
